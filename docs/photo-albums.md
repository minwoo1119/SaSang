# 지역 사진 앨범과 기존 데이터 호환

## 저장 형식

기존 배포 버전의 `regionPhotos`는 삭제하거나 배열로 변경하지 않는다. 이 필드는 각
지역의 대표 사진을 저장하는 호환 필드로 계속 기록한다.

```json
{
  "regionPhotos": {
    "korea:11680": { "id": "cover-photo" }
  },
  "regionPhotoAlbums": {
    "korea:11680": {
      "version": 1,
      "coverPhotoId": "cover-photo",
      "photos": []
    }
  }
}
```

- 기존 저장 데이터에 `regionPhotoAlbums`가 없으면 `regionPhotos`의 사진을 한 장짜리
  앨범으로 감싼다.
- 새 형식으로 저장할 때도 `regionPhotos`에 대표 사진을 함께 기록한다.
- 앨범 사진은 기존 `RegionPhoto` 형식을 그대로 사용하므로 URI, 촬영일과 crop
  transform이 보존된다.
- 저장 요청은 순서대로 실행해 빠르게 사진을 추가하거나 대표 사진을 바꿔도 이전
  상태가 나중 상태를 덮어쓰지 않게 한다.

## 화면 동작

- 지도는 앨범의 대표 사진 한 장을 지역 폴리곤에 표시한다.
- 선택된 지역의 하단 바를 누르면 사진 카드 앨범을 연다.
- 카드는 가로로 넘길 수 있고, 양옆 카드는 작게 기울여 현재 카드를 강조한다.
- 마지막 카드는 항상 사진 추가 카드다.
- 사용자는 앨범 안에서 대표 사진을 변경하거나 개별 사진을 제거할 수 있다.
- 장소 페이지는 지역당 카드 하나를 보여주고 전체 사진 수를 표시한다.

사진 제거는 우선 메타데이터에서만 수행한다. 앱 업데이트와 마이그레이션 중 사용자
원본이 의도치 않게 삭제되는 위험을 피하기 위해 앱 문서 영역의 파일은 즉시 지우지
않는다.
