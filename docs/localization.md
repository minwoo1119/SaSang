# 다국어 지원

## 지원 언어

Sasang 모바일 앱은 다음 네 언어를 지원합니다.

| 언어         | 코드    | 제품명 |
| ------------ | ------- | ------ |
| 한국어       | `ko`    | 사상   |
| 영어         | `en`    | Sasang |
| 일본어       | `ja`    | Sasang |
| 중국어(간체) | `zh-CN` | Sasang |

기존 사용자와 새 사용자의 기본 언어는 한국어입니다. 사용자는 `더보기 > 설정 > 언어`에서
언어를 바꿀 수 있으며, 변경 결과는 즉시 전체 UI에 반영되고 로컬 세션에 저장됩니다.

## 구현 구조

- `lib/core/l10n/sasang_localizations.dart`: 지원 로케일, UI 번역, 개수와 날짜 같은 동적 문구
- `lib/features/state/sasang_state.dart`: 현재 언어 상태와 변경 알림
- `lib/core/storage/sasang_storage.dart`: 선택 언어 코드 영속화
- `lib/app.dart`: Flutter 로케일과 로컬라이제이션 delegate 연결
- `assets/maps/korea/regions.json`: 시·군·구별 한국어·영어·일본어·중국어 이름과 상위
  행정구역 이름
- `assets/maps/world/countries.json`: 국가별 한국어·영어·일본어·중국어 이름

대한민국 지역명은
`scripts/map-data/sources/korea-region-localizations.json`의 검토된 코드별 매핑을 지도
생성기가 결합합니다. 영어명은 국가공간정보포털(V-World) 행정구역 속성, 일본어명은
Wikidata의 CC0 레이블, 중국어(간체)명은 MIT 라이선스의
`JayMuShui/chinese-global-compliant-geodata` 레이블을 기준으로 하며, 통합된 광역시·시는
동일한 명명 규칙으로 별도 검토합니다. `고성군`처럼 이름이 같은 지역은 5자리 지역 코드와
상위 행정구역으로 구분합니다.

세계 국가명은 `scripts/map-data/generate-maps.mjs`가 동일한 지도 원본에서 함께 생성합니다.
대한민국과 세계 지도 모두 생성 JSON의 번역 필드를 직접 수정하지 않습니다.

지역 검색은 현재 선택 언어에 한정하지 않고 네 언어의 지역명과 상위 행정구역명을 모두
대상으로 합니다. 따라서 영어 설정에서 `Yangpyeong`, 일본어 `楊平郡`, 중국어 `杨平郡`,
한국어 `양평군`을 어느 언어로 입력해도 같은 지역을 찾을 수 있습니다. 하이픈과 공백은
동일하게 취급합니다. 선택 지역 바와 검색 결과의 상위 행정구역명은 현재 앱 언어로
표시합니다.

## 번역 변경 규칙

1. 새 사용자 노출 문구는 `tr()`를 통해 표시하고 네 언어 값을 함께 추가합니다.
2. 변수나 개수가 들어가는 문구는 동적 패턴 번역과 해당 테스트를 함께 추가합니다.
3. 지역명 원천이나 생성 규칙을 바꾸면 지도 데이터 버전을 올리고 자산을 다시 생성합니다.
4. 언어 변경 후 현재 화면이 즉시 다시 빌드되는지 확인합니다.
5. 번역이 없을 때는 안전하게 한국어 원문을 표시합니다.
6. 대한민국 지역을 추가·통합·개명하면 코드별 번역 매핑과 상위 행정구역 매핑을 함께
   갱신하고, 생성 테스트의 100% 커버리지를 유지합니다.

## 검증

```bash
flutter analyze
flutter test
pnpm map:test
```

테스트는 네 언어의 대표 문구, 동적 날짜와 개수, 선택 언어 저장, 언어별 국내 지역명과
세계 국가명, 네 언어 검색, 지역 번역 매핑의 100% 커버리지를 검증합니다. UI 변경 PR에는
실제 에뮬레이터에서 캡처한 언어별 스크린샷을 포함합니다.
