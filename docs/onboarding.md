# 첫 실행 온보딩

## 목적

새 사용자가 첫 실행에 언어를 선택하고 Sasang의 핵심 흐름을 이해한 뒤, 사진의
로컬 저장에 동의하고 앱을 시작하도록 안내합니다.

## 화면 흐름

1. 한국어, English, 日本語, 简体中文 중 언어 선택
2. 대한민국·세계 지도와 지역 선택 안내
3. 방문 지역의 사진 추가와 지도 클리핑 안내
4. 장소별 기록과 이미지·영상 공유 안내
5. 사진이 서버로 전송되지 않고 기기에 저장된다는 안내와 시작 동의

언어를 바꾸면 현재 온보딩을 포함한 전체 UI가 즉시 재빌드됩니다. 완료 후에는
`더보기 > 설정 > 언어`에서 언제든지 변경할 수 있습니다.

## 상태와 호환성

- `hasCompletedOnboarding`: 기기에서 온보딩을 완료했는지 표시합니다.
- `hasStarted`: 현재 앱 시작/로그아웃 상태를 표시합니다.
- 로그아웃은 `hasStarted`만 변경하며 온보딩을 다시 표시하지 않습니다.
- 기존 세션 파일에 `hasStarted`가 있으면 이미 온보딩을 완료한 사용자로 간주하여,
  업데이트 후 기존 사용자에게 온보딩이 갑자기 표시되지 않게 합니다.
